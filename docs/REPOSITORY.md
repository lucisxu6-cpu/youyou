# 仓库材料说明

本仓库保存 youyou 的硬件与软件开发材料。首次整理上传日期：2026-10-31。

## 源码与文档

仓库收录当前插件与 USB 固件源码、测试、串口桥接、构建安装脚本、采购与接线指南、协议和生命周期说明、审查报告，并保留早期板卡与传感器验证脚本。

开发历史已移到 `DEVELOPMENT-HISTORY.md`；公开文档省略真实设备编号、会话 ID 和本机个人目录。原始本地记录继续保留。

当前 `pet-firmware.ps1` 会生成适合项目所在路径的工具配置。早期验证脚本使用 `arduino-cli.yaml`：如需运行，先从根目录的 `arduino-cli.example.yaml` 复制并填写实际工具目录。该本地配置不提交到 Git。

## 发布文件

[v0.3.6 发布页](https://github.com/lucisxu6-cpu/youyou/releases/tag/v0.3.6) 提供：

- `youyou-usb-0.3.6.zip`：可复用软件交付包，包含源码、插件包、应用镜像和离线指南。
- `loveandrobot-dsh-pet-usb-0.3.6.tgz`：单独的插件包。
- `SHA256SUMS.txt`：上述发布文件的 SHA-256，供下载后核对。

固件应用镜像在完整包的 `prebuilt` 中。它不是全片镜像；新板首次准备与已有板升级是两条不同路径，先读固件准备附录。

`package-release.ps1` 基于已构建的插件包和固件应用生成交付包；开发工具缓存本身不随包分发。更新 Markdown 后，打包时会重新生成两份离线 HTML 指南。

## 留在本机的内容

| 内容 | 原因 |
| --- | --- |
| `creative/` 中的影片、音频与创作素材 | 不属于本仓库的开发材料范围 |
| `.tools/` | 编译器缓存、下载、设备专属备份与临时维护脚本 |
| `logs/` | 运行日志、界面截图、原始本地记录及配置备份 |
| `build/` | 编译中间结果；可分发产物另放 Releases |
| `arduino-cli.yaml`、`.env`、用户档案与控制令牌 | 当前电脑配置和凭据信息 |

审查文档中的 `logs/...` 是本机证据位置，公开仓库不提供这些日志。审查结论及验证范围保留在文档中，不把缺少原始公开日志等同于新的验证结果。
