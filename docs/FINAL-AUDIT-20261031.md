# 最终全局审查：2026-10-31

审查对象：youyou USB 桌面原型，插件 0.3.6、固件 1.1.1、DeepSeek Harness Desktop 0.2.1-rc.5。硬件为 ESP32-S3-DEV-KIT-N8R8 和四片仍未装入娃娃的压力传感器。

## 结论

本轮列出的源码检查、自动测试、真实 USB 协议和桌面操作检查通过。未发现阻止当前桌面 USB 原型继续使用的缺陷。硬件运行路径没有加入 Flash 保存、GPIO 输出、Wi-Fi 或执行器控制。本轮没有刷写固件。

这是明确范围内的原型审查，不是对所有故障、硬件寿命或装配后表现的保证。长期温升、机械耐久和装入娃娃后的预压／识别效果尚未完成实测。

## 本轮发现并修复

1. 首次开场遇到忙碌 Agent 时，待开场状态可能一直保留，后续触碰也被阻挡，必须再次点聊天才能继续。0.3.6 在 Agent 空闲后自动完成待开场；临时提交失败最多每 10 秒尝试一次。暂停、归档、校准或配对时不自动开场；普通断开 USB 不妨碍已关联文字聊天。开场成功后清掉此前触碰候选，不补发旧触碰。
2. 可选诊断管道在异步启动回调中写 control.json，磁盘不可写时原先会产生未捕获异常。现在捕获错误、关闭该诊断入口并记录警告，不让诊断失败拖垮 Harness。正常配置保存仍采用原子替换，失败时不报告成功。

三个新增回归用例在修复前全部失败（含一次真实文件写入失败导致的未捕获异常），修复后与原有用例一起通过，共 47 项。测试只在临时目录和模拟宿主中注入故障，没有破坏用户实际配置。

## 本轮实际结果

- 自动测试：47 项全部通过；JavaScript 和 PowerShell 语法检查通过。
- 真机协议：14 项通过；错误 nonce、额外参数、NUL、嵌入 CR、超长行、合法 CRLF、新握手替换和超时停止均验证。
- 真机采样：200 帧，四路空载最小／最大值均为 4095，串口正常关闭。
- Harness 最终状态：USB 在线，固件 1.1.1，无错误，无配对草稿，回应已启用。
- 最终完整持久化配置与审查前深比较一致，包括名字、设备、基线、四个位置、唯一会话和启用偏好。检查期间未新增聊天，重启后未发送任何触碰或重复开场。
- 宿主本轮错误输出文件为空。实际界面显示插件 0.3.6、固件 1.1.1。

## 仍未验收的部分

- 装入娃娃后的预压、支撑、衣料厚度、温升、机械耐久与长期漂移；因此不能给出硬件寿命年限或零损耗承诺。
- 单片掉线的持续物理自检：空载 ADC 不能可靠区分所有断线情形。配对只能确认当时按片响应，不能替代断线检测电路。
- 单点压力只支持接触时序候选，不证明真正抓握、力度、抚摸轨迹或拥抱。
- 模型文字仍可能偏离人格／动作表述指导。本轮查看到历史回复中仍有身体动作描写；固件没有对应执行器，不把生成文字视为实际硬件动作。
- 两个存储系统之间无法保证进程突然崩溃时的严格一次性提交；模型网络、额度、宿主后续版本也不属于插件可独立保证的范围。
- 其他板型、新电脑工具准备及多宠物／跨电脑同步不在本轮兼容范围。
